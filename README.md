# Questionable Company 🪿

Public Nomi card game featuring Brenda, a sequined-vest goose judge.

## Deployment

Source code for version 1.3 must be placed at repository root: `index.html`, `game.js`, `package.json`, and `api/` handlers. Players supply their own Nomi API keys at runtime. No keys or tokens belong in this repository.

The game intentionally requires manual initiation of each round and reveal, with unrestricted conversation time between rounds.
